📌 一、前端部署 vs 接口部署

项目前端部署接口部署（后端）
部署内容HTML、CSS、JS、图片等静态资源Java 服务（Spring Boot 等）
处理内容展示页面、发起请求、用户交互接口逻辑、数据库处理、权限控制等
访问方式https://xxx/index.htmlhttps://api.xxx.com/user
部署方式静态资源服务器或 CDN后端服务器，监听 HTTP 请求

🧭 三、Spring Boot 如何区分静态页面和接口？

Spring Boot 默认：

  1. 查找是否有匹配的静态资源（如 /static/index.html）
  2. 没找到，则查找是否有 Controller 映射（如 /api/user）
  3. 都没有，则返回 404

🧩 四、SPA 单页逻辑是如何实现的？

前端 SPA 实现的核心流程是：

  1. 所有路径统一返回 index.html
  2. JS 加载后读取当前 URL
  3. 前端路由（Vue Router / React Router）解析路径
  4. 动态渲染对应组件

📦 六、前端到底是不是“静态文件”？

类型是否静态是否动态生成页面
传统 HTML 页面✅ 是❌ 否
Vue / React 应用✅ 是❌ 否（JS 渲染）
JSP / PHP / 模板渲染❌ 否✅ 是

虽然 Vue/React 的页面“看起来动态”，但都是靠 JS 在客户端动态渲染，不是服务器生成的。

✅ 总结

前端打包后的文件是静态资源，可部署到 CDN，由前端 JS 动态展示内容；Spring Boot 提供接口服务，前后端通过 HTTP 解耦配合，构建现代 Web 应用。
